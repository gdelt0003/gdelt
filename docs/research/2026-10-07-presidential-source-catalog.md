# 总统公开历史活动来源候选目录

**核验日期：** 2026-10-07

**用途：** 为仅展示公开、延迟历史材料的总统活动档案建立候选来源目录；不是自动采集许可清单，也不意味着已逐项验证 API、robots、服务条款、内容保留权或历史归档。

## 安全与证据边界

- 页面只讨论已经公开且至少延迟 24 小时的历史记录；不发布实时位置、未来行程、精确路线、专机/人员安保信息，也不从空域或交通数据反推行踪。
- **A** 为总统/白宫直接发布；**B** 为政府、议会、州/地方或主办机构的辅助记录，必须明确证明其出席/发言，日程公告不等于出席；**C** 为新闻/记者池发现线索，需回到原文或独立佐证；**D** 为空域/交通/天气上下文，只能解释环境，不是总统行程证据。
- 来源级别不是单条内容的真实性结论。建议将“官方公告已安排”“官方记录显示已发生”“独立报道”“机构独立佐证”“文件提及但非到场证据”“冲突”“更正/撤回”“未核实”分开标注；计划不能自动升格为已发生。
- 媒体内容需逐家审查版权/API/robots/paywall；社交平台内容需核实帐号归属、API/登录/费率/保留条款。网页可人工打开不等于允许自动抓取。
- 目录包括 101 个研究候选和 2 个补充候选（Truth Social、FDA）。Federal Register API 是同一文档库的另一访问通道；档案目录只适于历史检索，不是当前日程流。因此候选项数不等于独立发布方数。

## 建议的来源注册和数据契约

逐项接入前由云端审查任务填写 `source_id`、发布机构/账号、`source_class`（A/B/C/D）、官方身份状态、来源类型、公开 URL、API/Feed/HTML 获取方式、服务条款与 robots 检查日期、频率和限流、保留/版权策略、首次/最近成功抓取时间、解析器版本、历史覆盖与失效回退。初期优先白宫与总统事后记录、政府官方视频/社媒公开档案；联邦/州地方及场馆只作明确记载的独立佐证；媒体作发现线索；NOTAM 等 D 类永不进入“行程已确认”状态。

每条记录建议至少包括：原文 URL、发布方、原文发布时间、记录对应日期、云端采集时间、原文片段/视频时间码、存档副本标志、来源等级、证据状态、独立佐证计数、冲突/更正记录。云端流程需幂等、保留原始来源并失败即停止发布；前端单独显示原文日期、采集时间和“延迟历史资料”标识，不以采集成功的 LIVE 灯冒充所有数据源新鲜。
