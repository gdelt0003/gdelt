# GDELT 全球事件观察台

静态新闻与事件观察台。数据采集、分析、校验和 Pages 发布由 GitHub Actions 在云端执行；本地目录仅用于源码维护，不运行定时采集或重型数据任务。

当前首页提供可缩放的 GDELT 日级事件时间轴、历史滑块，以及从 GDELT 地理字段生成的近似新闻地点图。地点标记不是人员位置、活动现场或路线；地图/时间轴数据与外部底图会由浏览器访问固定版本的 CDN/地图服务。

**产品范围说明：** 当前站点是 GDELT 全球新闻观察台，不是总统行踪站。总统公开活动若另行实现，只能展示公开且至少延迟 24 小时的历史记录；不展示实时位置、未来行程或精确路线。FAA NOTAM/TFR 等只能作空域背景，不能用来推断总统行踪。
